R1-B · EXPLICIT OPERATOR-APPROVED CONTAINER TESTS

Testing in the tool shed.

Actual local Node test runs in a constrained Docker container, never on the host. Requires Docker and an image pinned to its immutable ID or digest.

Container jobs REAL LOCAL JOB COUNTS

Reading local job receipts...

Test receipts LOCAL OUTPUT HASHES · NOT SIGNED

Reading test results...

No auto-run, remote job submissions, or project scripts on Windows. Only the operator can enqueue and run via node src/sandbox-cli.mjs. Workers use a preloaded immutable Docker image, no container network, read-only filesystem, dropped capabilities and limits. These controls reduce risk but are not a guarantee against container escapes. Run only code you're prepared to test on your Docker host.

R1-D1: Use node src/recovery-cli.mjs doctor to inspect interrupted jobs in both worker lanes. A local operator may explicitly mark an interrupted job ABORTED_UNVERIFIED after confirming the worker has stopped. Nothing is retried, deleted, or promoted to PASS.

FIRST STEPS

Make yourself at home.

Plant the first post.

Create your first bare repository.

02 / SERVE

Light up the porch.

Run the local dashboard and Git daemon.

npm start

Check the floorboards.

node src/cli.mjs verify hello-world
