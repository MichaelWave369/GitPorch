FIRST STEPS

Make yourself at home.

Three commands, one porch. Works even when GitHub doesn't.

01 / CREATE

Plant the first post.

Create your first bare repository.

node src/cli.mjs init hello-world
02 / SERVE

Light up the porch.

Run the local dashboard and Git daemon.

npm start
03 / VERIFY

Check the floorboards.

Verify Git object integrity, not CI.

node src/cli.mjs verify hello-world
