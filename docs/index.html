UP NEXT: THE PORCH CREW

Our build runners. Our rules.

R1-A provides real local Git integrity checks, and R1-B adds manually approved Node.js test runs in restricted Docker containers. Both are single-user local tools. This static public page does not connect to those jobs or show real test statuses. R1-C adds pinned-image verification and unsigned local output hashes. R1-D1 adds an operator recovery doctor that can only close interrupted jobs as ABORTED_UNVERIFIED. R1-D2 introduces manually signed local reports verifiable offline with a trusted public key; those signatures are not independent proof that a build ran honestly. This public showcase has no access to signing keys or job reports. R1-D3 adds an optional second-key offline countersignature. R1-D4A adds a local allowlist and revocation veto. R1-D4B1 adds an optional password-encrypted new operator key for local signing, without migrating older keys. R1-D4B2A adds a nondestructive passphrase rewrap with a staged encrypted copy, preserving the existing signing identity. None of these static public examples expose vaults, private keys or actual test records, and none prove independent CI execution.
